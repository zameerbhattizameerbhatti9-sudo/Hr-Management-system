# HR Management System

A modern HR Management System built with Next.js, React, and TailwindCSS.

## Features

- 👥 Employee Management
- 📊 Attendance Tracking
- 🗓️ Leave Management
- 💰 Salary Management
- 📈 Performance Reviews
- 🔐 Role-based Access Control

## Tech Stack

- Next.js 14
- React 18
- TailwindCSS 3
- TypeScript
- Radix UI Components
- Lucide Icons

## Getting Started

### Prerequisites

- Node.js 18+ 
- npm or yarn

### Installation

1. Clone the repository:
```bash
git clone <your-repo-url>
cd hr-management
```

2. Install dependencies:
```bash
npm install
# or
yarn
```

3. Run the development server:
```bash
npm run dev
# or
yarn dev
```

4. Open [http://localhost:3000](http://localhost:3000) in your browser.
